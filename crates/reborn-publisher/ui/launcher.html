Launcher update

Build the launcher installer and offer it to every player as an update.

How this works

The build runs the same script a release build uses, in the repository this computer is configured with. The installer is hashed and uploaded before the small file that names it, so no player is ever pointed at a file still in flight. A version that is not newer than the one on the server is refused before the build starts.
