Build an ISO

Build a playable disc from a roster, read one back, sync a memory card, and publish a game patch.

How this works

Building runs the Reborn Builder against a base image and a roster. A game patch is the difference between the disc players already have and a new one, published so the launcher can patch a player's disc in place without downloading a whole image.
