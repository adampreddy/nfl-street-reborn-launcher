League files

Publish the league build (disc + the textures that differ from retail) or the league seed. Members only.

How this works

Each one becomes a new members-only version and a new signed release carries every other thing forward. Its files go to the private league bucket first; only then do the manifest and the release go to the public server. League members download the files through short-lived links; the public CDN never serves them.
