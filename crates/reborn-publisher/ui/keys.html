Keys and settings

The signing keys, the stored secrets, and the paths this app uses.

How this works

A release is signed with the everyday key on this computer; every shipped launcher trusts it. The rotation key exists to replace the everyday key if it ever leaks, and belongs offline. A stored secret is never shown again, only whether it is stored.
