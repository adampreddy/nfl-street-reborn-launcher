Textures, runtime, mods

Publish a folder of textures, a Dolphin runtime, or a mods folder as the next version.

How this works

The folder is hashed file by file. Files the server already has are not sent again, so a texture update is usually small. A new signed release is written that carries every other thing forward unchanged. A runtime folder is checked first: one the launcher has already started (logs, a User folder) is refused, because it would offer every player a pointless update.
