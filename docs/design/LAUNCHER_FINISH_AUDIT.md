# Launcher finish audit

The active goal remains: finish the launcher so it is polished, beautiful, functional, and contains the important features. The user's concrete requests include controller feedback, the reference UI style, a store-style Mods page with solid color artwork placeholders, practical Dolphin settings, and Online with manual Netplay while matchmaking is pending.

Implemented in this pass:

- Isolated controller artwork classes from application buttons. Rendered-pixel tests confirm pressed feedback for Xbox One, DualShock 4, and DualSense. Existing four-player assignment and input-capture tests still pass.
- Added a restrained shared appearance, with consistent typography, section tabs, fields, cards, and dialog styling. Browser layout checks cover 1280px and 800px widths. Onboarding remains functional at 800x600.
- Mods now uses searchable cards, category and enabled filters, a featured collection area, details, and enable/disable actions. Core conflict resolution remains authoritative. Missing packages, failed activation, and empty libraries remain visible. Artwork uses solid color placeholders, as requested. This is the installed mod collection; no remote marketplace catalog or purchasing service has been fabricated.
- Settings starts with Open Dolphin and has General, Display, Audio, Saves, Updates, and Files & storage sections. The native backend edits only allowed INI keys. Settings survive the launcher's generated configuration, including subsequent edits made directly in Dolphin. Required Reborn compatibility settings remain managed. Save files are never overwritten or deleted by these controls. Editing is refused while Dolphin is running. The reason editing is unavailable appears above the controls and distinguishes a failed process check from a running emulator.
- Manual Netplay prepares the installed game, controller mappings, and configuration, fills connection settings, and opens Dolphin. The page explicitly instructs the user to finish through Tools > Start Netplay. The launcher retains a session guard until that Dolphin process closes. Matchmaking is marked coming soon.
- Controller navigation stays within mod dialogs. Sliders support A to edit/apply, D-pad to adjust, and B to cancel. Input pauses during asynchronous saves to prevent focus from jumping to another action.
