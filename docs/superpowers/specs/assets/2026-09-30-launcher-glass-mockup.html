What changed

  • Layout identical; only the look changed
  • Stats = Stats v2 + Profile (feat/stats-profile-v2), restyled; behaviour and wording unchanged
  • Motion: fades + short slides only, 120/180/240 ms, one easing; sliding nav marker and tab indicator; menus settle from their anchor; save bar rises in; best-of-3 rows expand; all off with reduced motion
  • Settings › Display › Slow animations: ON by default (480/720/960 ms); off = quick (120/180/240 ms)
  • Mods/Music/Controllers/Stats: sample data, same layouts as today
  • One token set for every page (fixes 4 backgrounds, 2 reds)
  • Sidebar + page sit on the OS glass; cards are frosted panels
  • Settings › Display › Window glass: players can turn glass off; off = the same solid dark look as Linux / Deck
  • No glows anywhere; focus is a plain white ring
  • Play: account + playtime top-right; Play now with a ⋯ Game details button beside it; Ready to play under it; glass action strip; Display works like the other cells (opens a small menu)
  • Settings: one floating Save bar at the bottom, only when something changed (content scrolls above it, never under it) instead of 4 Save buttons; Browse+Save becomes "Change…"; shorter Dolphin card
  • Controller prompts + white focus ring only while a controller is driving the launcher (switch Last input)
