# beta.4: what Adam found in beta.3, and the fixes

Adam's list from testing 3.0.1-beta.3 on 2026-09-10, in the order they are
being done. Each item names the cause found, the change, and how it is proven.

## 1. Dolphin settings are wrong ("launches weird, not in the right window")

**Cause.** A new Dolphin user folder is created empty and, at launch, the
launcher writes only its own required keys (backend, MEM1 size, hires
textures, fullscreen preference, ports). Nothing from the Dolphin Adam tuned
(dual core, MSAA 4x, forced filtering, aspect ratio, the Gecko codes and
game settings in `GameSettings\GN7E69.ini`) ever reaches a player.

**Change.** The runtime component carries a baseline `User\Config\Dolphin.ini`,
`User\Config\GFX.ini` and `User\GameSettings\GN7E69.ini`, made from the old
Dolphin's live files with the developer-only parts removed (analytics ID,
ISO paths, default ISO, netplay identity, texture dumping). Every NEW user
folder is seeded from that baseline before the launcher's required keys are
layered on, so the required keys still win. Existing user folders are not
touched: a player's own edits survive.

Script: jobs tmp `make_dolphin_baseline.py` → `C:\Reborn Origin-stage\runtime-3.1.0-clean\User\...`.
Runtime republished as 1.1.1.

**Proof.** Unit test: seeding copies the three files and a later launch keeps
them while adding the required keys. Real window: a fresh setup on this PC,
then read the user folder's files.

## 2. Start with NSRV3 and the textures, no update needed

**Cause.** The 3.0 design imported the player's own disc and patched it. Adam
wants the installer to carry NSRV3 outright, as 2.1 did.

**Change.** `build.ps1 -GameImage <NSRV3.iso>` stages `content\games\NSR.iso`
plus its sha256. Setup: "Start fresh" imports the shipped image (hardlink,
same volume) with no disc prompt; "I already have Reborn" brings saves and
settings over but boots the shipped image, never the old disc. The import
bundle stays for a player who chooses their own disc. Textures already ship
and seed (0 fetches, proven on release 6).

**Proof.** Real window: fresh setup and migration both end on
`library/imported/98bfe6bf…/NSR.iso` with no game download.

## 3. Mods library is empty

**Cause.** Only the two controller packs ship, and the library hides
controller packs by design (they belong to the Controls page).

**Change.** All twelve of Adam's packs ship under `content\mods\packages`,
seed into `mods\packages`, and are published as the `mods` component so the
first check adopts them and later updates work.

## 4. Smaller changes

- Text: "Sign in with Discord to track your stats from your games."
- Text: "Ready to play" instead of "NFL Street 2 · GameCube" before the first game.
- Setup window is a fixed size while first run is incomplete (no scrollbars on
  the controller step).
- Controller step: choosing a controller is enough to continue; the input
  tester no longer leaves the wizard marked busy.
- Copy button on the launch error, for pasting into a forum post.
- Patch notes button opening the website's blog, in place of the release-notes
  paragraph in Settings.
- Uninstall: a shortcut in the install folder, and a button in Settings.
- Stats gets its own page and sidebar entry, moved out of Settings.
- Content and launcher downloads show a percentage and a visible bar.

Already fixed in beta.3: the logo leaving setup mid-import.
